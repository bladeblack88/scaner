# Wi-Fi Camera Scanner

Небольшой локальный сканер сети для Android через Termux. В браузере открывается мобильная панель, а Python на телефоне проверяет IP-адреса и распространённые порты камер.

## Возможности

- Определяет IPv4-адрес Wi-Fi (предпочитает интерфейс `wlan0`).
- Проверяет устройства в локальной подсети (не более одной /24 сети).
- Проверяет TCP-порты: 80, 81, 443, 554, 8000, 8080, 8081, 8554, 8899, 34567.
- Для HTTP-портов пытается прочитать заголовок Server и HTML title.
- Для RTSP-портов отправляет запрос OPTIONS.
- Показывает вероятные признаки камеры в браузере.

## Установка на Android

1. Установите Termux из [F-Droid](https://f-droid.org/packages/com.termux/) или официального источника проекта.
2. Подключите телефон к той же Wi-Fi сети, что и проверяемые устройства.
3. В Termux выполните:

```sh
pkg update -y
pkg install python iproute2 git -y
git clone https://github.com/bladeblack88/scaner.git
cd scaner
```

## Запуск

```sh
python scanner.py
```

Откройте браузер **на этом же телефоне** и перейдите по адресу:

```
http://127.0.0.1:8765
```

Нажмите «Начать сканирование».

Остановить сервер: `Ctrl+C` в Termux.

## Ограничения

- Это поиск открытых TCP-портов, а не гарантированное распознавание камер.
- RTSP и ONVIF могут быть отключены, скрыты за облачным приложением или недоступны из локальной сети.
- Скрипт не получает видеопоток, не обходит авторизацию и не подбирает пароли.
- Проверяется только локальная частная сеть /24. Сети с изоляцией клиентов Wi-Fi могут не показывать устройства друг другу.
- HTTPS-проверка использует диагностический запрос и не подтверждает подлинность сертификата.
- Для доступа к интерфейсу сканера сервер привязан к 127.0.0.1, то есть доступен только на самом телефоне.

Используйте только в сети, которой вы владеете или на проверку которой получили разрешение.
